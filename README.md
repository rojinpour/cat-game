# 🐾 Cat Dash: Fish Quest

A cute, fast little **browser game** where you play as a tiny cat, collect fish 🐟, and dodge angry roombas 🤖 that chase you around a dreamy room.

Built as a **single HTML file** with **vanilla JavaScript + Canvas** — no frameworks, no build step, just vibes.

---

## ✨ Features
- **Playable cat character** with smooth movement + cute face animations
- **Collectible fish** that bob and glow
- **Enemy roombas** that chase you (difficulty increases as you level up)
- **Dash ability** with a visible cooldown bar
- **Particles + screen shake** on hits and pickups
- **Pause mode**
- **Responsive canvas** (handles high-DPI screens)

---

## 🎮 How to Play
**Goal:** Collect fish to gain points and level up. Survive as long as you can.

### Controls
- Move: **WASD** or **Arrow keys**
- Dash: **Shift** (short burst when dash bar is full)
- Pause/Resume: **P**

### Tips
- Save your dash for when a roomba gets too close.
- Corners are risky—roombas love to trap you.

---

## 🚀 Run Locally

### Option 1: VS Code + Live Server (recommended)
1. Install the **Live Server** extension in VS Code
2. Open this project folder
3. Right-click `index.html` → **Open with Live Server**

### Option 2: Open in browser
Just double-click `index.html`.
